# Bhanvi Solar — Backend

NestJS REST API for the Bhanvi Solar platform. See the [root README](../README.md) for full
setup instructions, environment variables, architecture notes, and deployment guidance.

Quick start:

```bash
cp .env.example .env
npm install
npm run seed
npm run start:dev   # http://localhost:4000/api — Swagger docs at /api/docs
```
